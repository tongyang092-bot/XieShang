# 偕裳 XieShang Windows 可执行版

## 运行方法

1. 完整解压比赛提交压缩包，不要只从压缩包预览界面直接运行。
2. 双击 `XieShang.exe`。
3. 程序会启动本地服务，并自动在默认浏览器打开页面。
4. 运行期间请保留命令窗口；关闭窗口或按 `Ctrl+C` 即可停止。

默认访问地址为：<http://127.0.0.1:8000>

## 数据位置

首次运行后，程序会在可执行文件旁创建 `data` 目录：

- `data/xieshang.db`：本地 SQLite 数据库。
- `data/uploads/`：用户上传及生成的图片。

删除 `data` 目录可恢复为全新演示数据。正式演示前请先备份需要保留的内容。

## API Key 安全说明

比赛提交包不包含任何 API Key，未配置密钥时仍可浏览页面和演示衣橱、发现、个人中心等本地功能，但真实 AI 生成接口不可用。

如需在自己的电脑上演示 AI 功能：

1. 将 `配置模板.env.example` 复制为 `.env`，放在 `XieShang.exe` 同级目录。
2. 仅在本机 `.env` 中填写 `ALIYUN_API_KEY` 或 `DASHSCOPE_API_KEY`。
3. 重新启动 `XieShang.exe`。
4. 上传比赛材料前删除 `.env`，只保留空白模板。

请勿通过聊天、截图、源代码、压缩包或录屏泄露密钥。

## 常见问题

- 提示端口 8000 被占用：先关闭此前运行的 XieShang 窗口，或在本机 `.env` 中修改 `BACKEND_PORT`。
- Windows 安全提示“未知发布者”：当前比赛版未购买代码签名证书，这是未签名自制程序的常见提示。
- 双击后浏览器没有打开：保留命令窗口，手动访问命令窗口显示的地址。
- AI 功能提示鉴权失败：确认本机 `.env` 的 Key 类型、地域端点和模型权限正确。

## 比赛提交建议

直接上传 `XieShang-Windows-x64.zip`，不要上传以下内容：

- 项目根目录或 `backend` 目录下的 `.env`。
- `data` 运行数据目录。
- 含真实 API Key 的截图、日志或说明文件。
